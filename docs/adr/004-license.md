# 004 - GPLv3

Date: 2026-09-19
Status: accepted


## Decision

GNU GPLv3.


## Reasoning

Skull Browser is GPLv3, being a luakit fork. Skull Wins shares no code with
either, so the licence was a free choice.

It went to GPLv3 anyway. The design owes a great deal to luakit even where the
code does not, the work borrows its conventions deliberately, and matching the
licence removes any question about provenance. It costs nothing on a project
that is not being sold.

LICENSE is in the first commit rather than added at release, because a public
repository with no declared licence is worse than any particular choice.
